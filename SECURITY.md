# Security Policy

## Supported Versions

Security updates are applied to the `main` branch.

| Version | Supported |
| ------- | --------- |
| main    | yes       |

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use one of the following options:
1. GitHub Security Advisories (preferred private reporting flow).
2. Contact repository maintainers directly.

When reporting, include:
- affected component or file
- reproduction steps
- impact assessment
- proposed mitigation if available

We will acknowledge receipt as soon as possible and provide a remediation plan after triage.
