# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment include:
- Being respectful and constructive.
- Accepting feedback gracefully.
- Focusing on what is best for the community and project quality.

Examples of unacceptable behavior include:
- Harassment, discrimination, or personal attacks.
- Publishing private information without permission.
- Any conduct that is inappropriate in a professional setting.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing acceptable behavior.

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, and discussions.

## Reporting

Report unacceptable behavior through the repository maintainers or GitHub reporting tools.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with this Code of Conduct.

This project follows the spirit of the Contributor Covenant.
